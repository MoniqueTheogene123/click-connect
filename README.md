# Click Connect Functional Specification

* An application to help employees find co-workers with specific skills. "Facebook for work"

Pain Points:
+  Need for effective remote communication
+ Relying on someone else to reply
+ Tunnel vision
+ Wasting time
+ Decision making

Solution:  Create an intelligent search tool based on personas.

User Stories:
As an employee, I want to be able to search for people's skills so I can see who has the skills I need.
As an employee, I want to be able to add and update projects I have worked on, so that my co-workers can see examples of my work.
As an employee, I want to be able to add and update my skills as I learn new skills, so that my co-workers can find me by my updated skills.
Stretch Goals
Support multiple organizations (multi-tenant architecture)
Category: Pain Killer - Aleviate frustration and find skillsets
